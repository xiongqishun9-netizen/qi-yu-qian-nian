# 参考资料分析

## CGTN《The Song, Painted》的叙事方法

参考站以开场入口建立主题，再让观者逐步进入图像中的对象与故事。可借鉴的方式是**先整体感知，后局部探查，最后提供可回查的深读信息**；原站的绘画素材、版式和代码没有用于本项目。

《器语千年》将其转译为六幕固定画幅：

1. 序章用可见的 HTML `START` 按钮开启展卷。
2. 第一章采用横向馆藏图廊，先展示秦、汉实物形制差异，再进入研究模型。
3. 第二章从整体走向结构线、分离和编号，点击部件查看证据状态。
4. 第三章以分阶段叙事呈现比较性铸造与加工流程。
5. 第四章从单兵持握推进至张弦方式比较与军阵编组；画面是情境插画，关键事实连接到官方馆藏资料。
6. 器藏将概念模型及已探索状态归档。旧版独立“留痕”第五章已取消，馆藏来源和证据状态分别进入相关章节与档案。

滚轮、键盘、按钮和触屏手势都与上述阶段对应。每个可见的操作入口都应触发可观察的状态变化。

## 参考视频的方法转译

参考视频中的空间感来自前、中、后景图层和缓慢的相机推进。本项目用背景氛围图、纸本纹理、分层 SVG 与淡入过渡制造纵深；馆藏实物照片保持独立展示，不参与概念结构的变形。初版以可读的知识路径为主，后续有授权测绘图时再增强精确的 2.5D 结构运动。

## 证据边界

- 馆藏图片是实物参照，按藏品页面分别标注年代、馆藏和来源。
- AI 图用于展览氛围与使用场景想象，不能证明文物结构、服饰或阵法。
- `QY-CB-001` 为研究性概念模型，不指认为某件出土弩机。
